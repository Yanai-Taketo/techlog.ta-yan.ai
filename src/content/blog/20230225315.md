Windows 7 を新規にインストール後にWindows Upadteをかけると、「80072EFE Windows Updateで不明なエラーが発生しました」など、ダウンロードに失敗することがあります。

これらの問題は、「Windows 7 用更新プログラム (KB3138612)」をインストールすることで解決できる場合があります。

## Microsoft Update カタログにアクセス

::linkcard[Microsoft Update カタログ(KB3138612)]{url="https://www.catalog.update.microsoft.com/Search.aspx?q=KB3138612" site="<br>Microsoft" image="/wp-content/uploads/sng/1afb4ce10a469e709e8e3901d10702cb.gif"}

お使いの環境のOSに合わせて、以下のタイトルに一致する「ダウンロード」ボタンを押下する。

|  |  |
|---|---|
| OS | タイトル |
| Microsoft Windows 7 (32bit) | Windows 7 用更新プログラム (KB3138612) |
| Microsoft Windows 7 (64bit) | Windows 7 for x64-Based Systems 用更新プログラム (KB3138612) |

![](/wp-content/uploads/2023/02/2023022502001.png)

:::box
ダウンロードしたファイルをWindows 7 の環境で実行することで、

「Windows 7 用更新プログラム (KB3138612)」がインストールされ、Windows Updateができるようになります。
:::
