インターネットブラウザー(IEやEdge)を使わずに、Google Chromeをインストールしたいときの対処法

::::box
:::memo{title="注意点"}

:::

本記事の方法で実施するには、「Windows10 1709以降」または「Windows 11」が必要です。

詳細は「winget ツールを使用したアプリケーションのインストールと管理」をご覧ください。

::linkcard[winget ツールを使用したアプリケーションのインストールと管理]{url="https://learn.microsoft.com/ja-jp/windows/package-manager/winget/" site="Microsoft" image="/wp-content/uploads/sng/3c8966dbf0edc2b19875757a4f3b0ec4.png"}
::::

## Edge(ブラウザー)を使わずにGoogle Chromeをインストール

Windowsでコマンドプロンプトを起動します。

(Ctrl + R → 「cmd」と入力し、エンターで起動)

コマンドプロンプトに以下の文字を入力します。

:::box
<div class="code-label">コマンドプロンプト</div>

```bat
winget install Google.Chrome
```
:::

:::box
すべてのソース契約条件に同意しますか?と表示された場合は、「Y」を入力してください。
:::

:::box
<div class="code-label">コマンドプロンプト</div>

```bat
すべてのソース契約条件に同意しますか?
[Y] はい  [N] いいえ: Y
```
:::

![](/wp-content/uploads/2023/03/2023030501001.png)

:::box
しばらくするとインストーラーが自動的に起動され、Google Chromeが自動的にインストールされます。
:::
