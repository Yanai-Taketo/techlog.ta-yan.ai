IPアドレスを設定する際の手順備忘録

:::box
<div class="code-label">CentOS 7</div>

```text
sudo vi /etc/sysconfig/network-scripts/ifcfg-ens[任意の数字]
```
:::

:::box
<div class="code-label">ifcfg-ens...</div>

```text
TYPE=Ethernet
PROXY_METHOD=none
BROWSER_ONLY=no
BOOTPROTO=dhcp→none
DEFROUTE=yes
IPV4_FAILURE_FATAL=no
IPV6INIT=no
IPV6_AUTOCONF=yes
IPV6_DEFROUTE=yes
IPV6_FAILURE_FATAL=no
NAME=enp0s3
UUID=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
DEVICE=enp0s3
ONBOOT=no→yes
IPADDR=XXX.XXX.XXX.XXX
PREFIX=24
GATEWAY=XXX.XXX.XXX.XXX
DNS1=XXX.XXX.XXX.XXX
DNS2=8.8.8.8
```
:::

:::memo{title="注意！"}
起動直後は定義したIPアドレスで通信できるのに、

しばらくすると接続できなくなる場合、「BOOTPROTO」の設定を忘れている可能性があります。
:::

::::box{title="ついでに・・・"}
ホスト名の変更は以下の方法で実施できます。

:::box
<div class="code-label">CentOS 7</div>

```text
sudo hostnamectl set-hostname [ホスト名]
```
:::
