Oracle データベースの EXPORT ファイル（.dmp）を **Oracle 環境なしで**解析・閲覧できる Windows デスクトップアプリケーション「**OraDB DUMP Viewer**」を公開しました。

DB 管理者やデータ移行チームの方で、「.dmp ファイルの中身をちょっと確認したいだけなのに Oracle を入れないといけない…」と感じたことはありませんか？ OraDB DUMP Viewer はまさにその課題を解決するツールです。

- 🌐 公式サイト: [https://www.odv.dev/](https://www.odv.dev/)
- 💻 GitHub: [https://github.com/OraDB-DUMP-Viewer/OraDB-DUMP-Viewer/](https://github.com/OraDB-DUMP-Viewer/OraDB-DUMP-Viewer/)

## OraDB DUMP Viewer とは

OraDB DUMP Viewer は、Oracle の `EXP`（レガシー Export）および `EXPDP`（DataPump）形式の .dmp ファイルを、**Oracle データベースや Oracle Client のインストールなしに**解析・閲覧できるツールです。C ネイティブ DLL による高速な解析エンジンを搭載しており、テーブル一覧を瞬時に取得し、必要なテーブルだけをオンデマンドで読み込みます。

## 主な特長

### 🔍 Oracle 不要の DMP 解析

Oracle データベースや Client をインストールすることなく、.dmp ファイルのスキーマ・テーブル・データを解析・閲覧できます。

### 🌳 スキーマ・テーブルのツリー表示

DMP ファイル内のスキーマを階層ツリーで表示。テーブル一覧から名前・所有者・行数をすばやく把握し、ダブルクリックでデータをプレビューできます。

### 🔎 高度な検索機能

12 種類の演算子（含む、前方/後方一致、Null 判定など）を AND/OR で組み合わせた SSMS ライクな複合条件検索で、目的のデータを瞬時に発見できます。

### 📊 大容量データ対応

ページング機能で数百万行クラスのデータもスムーズに閲覧可能。進捗バーで解析状況（処理速度・残り時間・完了予想）をリアルタイム表示します。

### 🪟 MDI マルチウィンドウ

複数の DMP ファイルやテーブルプレビューを同時に開き、重ねて表示・並べて表示・アイコン整列など自由にレイアウトして作業できます。

### 🌐 多言語対応（v1.2.0 New!）

最新バージョン v1.2.0 では、日本語/英語の切替に対応しました。ヘルプメニューから言語を変更できます。

## 豊富なエクスポート機能

閲覧するだけでなく、さまざまな形式にデータをエクスポートできます。

| 形式 | 説明 |
|---|---|
| **CSV** | RFC 4180 準拠の CSV 出力（単一テーブル / 一括） |
| **SQL スクリプト** | Oracle / PostgreSQL / MySQL / SQL Server 対応の INSERT 文生成 |
| **Excel** | .xlsx 形式での出力 |
| **Access** | .accdb 形式での出力 |
| **SQL Server** | SQL Server への直接エクスポート |
| **ODBC** | ODBC 接続による任意のデータベースへの出力 |
| **LOB ファイル抽出** | BLOB / CLOB / NCLOB データを個別ファイルに保存 |

## 対応データ型

`NUMBER` / `DATE` / `TIMESTAMP` / `VARCHAR2` / `CHAR` / `CLOB` / `BINARY_FLOAT` / `BINARY_DOUBLE`

1. **ライセンスを取得** — [公式サイト](https://www.odv.dev/register)で登録（個人・教育機関は無料）

3. **DMP ファイルを開いて閲覧** — .dmp ファイルを開くだけでスキーマ・テーブル・データがすべて可視化
