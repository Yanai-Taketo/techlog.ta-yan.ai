Windows 7 Service Pack 1(KB976932)をMicrosoft 公式からダウンロードする方法

## Microsoft Update カタログにアクセス

::linkcard[Microsoft Update カタログ(KB976932)]{url="https://www.catalog.update.microsoft.com/Search.aspx?q=KB976932" site="<br>Microsoft" image="/wp-content/uploads/sng/1afb4ce10a469e709e8e3901d10702cb.gif"}

お使いの環境のOSに合わせて、以下のタイトルに一致する「ダウンロード」ボタンを押下する。

|  |  |
|---|---|
| OS | タイトル |
| Microsoft Windows 7 (32bit) | Windows 7 Service Pack 1 (KB976932) |
| Microsoft Windows 7 (64bit) | x64 ベース システム用 Windows 7 Service Pack 1 (KB976932) |

![](/wp-content/uploads/2023/02/2023022501001.png)

:::box
ダウンロードしたファイルをWindows 7 の環境で実行することで、

Windows 7 Service Pack 1がインストールされます。
:::
