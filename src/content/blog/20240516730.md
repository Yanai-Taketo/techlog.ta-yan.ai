クラウドストレージ「Box」を使用してファイルを共有する際、ファイルアップロードをした後に、共有リンク作成・コピーと手順が多く、手間がかかります。

この状況を改善するため、Pythonを使用しファイルアップロードから共有リンク作成までを自動化するプログラムの作成を実施しました。

## ソースコード

最新のソースコードは、Githubにて公開しています。

個人的に使用するのを目的に開発しているため、エラー処理等が十分でない箇所があるかもしれません。

::linkcard[YANAI-Taketo/BOX-Sharing]{url="https://github.com/YANAI-Taketo/BOX-Sharing" site="GitHub" image="/wp-content/uploads/sng/bc946f70eb4e266241828b22b8fb544c.jpg"}

::::box
実行には関連するパッケージのインストールが必要です。

同梱している「packages」のwhlファイルから、または下記のコマンドでパッケージをインストールしてください。

:::box
```text
pip install configparser boxsdk flask
```
:::
::::

## OAuth 2.0資格情報作成

プログラムの実行には、OAuth 2.0認証が必要です。

[Box Developers](https://app.box.com/developers/console)にて、認証情報を作成してください。

<figure>

![](/wp-content/uploads/2024/05/2024051501001.png)

<figcaption>「カスタムアプリ」を選択</figcaption>
</figure>

<figure>

![](/wp-content/uploads/2024/05/2024051501002.png)

<figcaption>「アプリ名」と「目的」に任意の情報を入力し、<br>「次へ」をクリック</figcaption>
</figure>

<figure>

![](/wp-content/uploads/2024/05/2024051501003.png)

<figcaption>「ユーザー認証(OAuth 2.0)」を選択し、<br>「アプリの作成」をクリック</figcaption>
</figure>

<figure>

![](/wp-content/uploads/2024/05/2024051501004.png)

<figcaption>「クライアントID」と「クライアントシークレット」をコピー。<br>「リダイレクトURL」に[http://localhost:5000/callback]を設定。<br>「Boxに格納されているすべてのファイルとフォルダへの書き込み」にチェックをいれ、<br>「変更を保存」をクリック。</figcaption>
</figure>

![](/wp-content/uploads/2024/05/image.png)

::::box
コピーした「クライアントID」と「クライアントシークレット」は、env.iniに貼り付ける。

:::box
<div class="code-label">env.ini</div>

```text
[box]
client_id = クライアントID
client_secret = クライアントシークレット
access_token = [空白]
refresh_token = [空白]
folder_id = フォルダID
```
:::

folder_idには、アップロードしたいフォルダのページを表示した際、URL(/folder/ 配下)に表示される数値を貼り付ける。

![](/wp-content/uploads/2024/05/image-1.png)
::::

## プログラムの実行

プログラムは、「main.py」を実行することで起動される。

:::box
<div class="code-label">cmd</div>

```bat
python main.py
```
:::

プログラム実行後は、[http://localhost:5000](http://localhost:5000)にアクセスし、BOXにログインする。

以降は、「[http://localhost:5000/upload](http://localhost:5000/upload)」にアクセスすることで、ファイルアップロードから共有リンク作成までを自動化することができる。
