:::box
実行にはMicrosoft Visual Studioのインストールが必要です。

インストールされていない場合は、Visual Studioのインストールを実施してください。

::linkcard[Visual Studio: ソフトウェア開発者とチーム向けの IDE およびコード エディター]{url="https://visualstudio.microsoft.com/" site="Visual Studio" image="/wp-content/uploads/sng/93c17bf02ba622c5ddcb34dc78cdebce.png"}
:::

## Developer Command Prompt for VS 2022を開く

![](/wp-content/uploads/2023/12/2023120301001.png)

## 以下のコマンドを実行

:::box
<div class="code-label">cmd.exx</div>

```text
dumpbin /headers "探したいEXE/DLLのパス" | findstr machine
```
:::

:::box
出力された内容に、

「x64」と表示されていたら64bit版

「x86」と出力されていたら32bit版です。
:::
