Google Charts APIを使って、QRコードを作成するときの備忘録

<div class="code-label">URL</div>

```text
https://chart.googleapis.com/chart?chs=[width]x[height]&cht=qr&chl=[data]
```

|  |  |  |
|---|---|---|
| chs=[width]x[height] | 必須 | 幅×高さ(同じ値を指定) |
| cht=qr | 必須 | QRコード作成 |
| chl=[data] | 必須 | エンコードするデータを指定 |
| choe=[CharCode] | オプション | 文字コード<br>・UTF-8<br>・Shift-JIS<br>・ISO-8859-1 |
| chld=[ErrorLevel] | オプション | 誤り修正レベル<br>・L - 約7%<br>・M - 約15%<br>・Q - 約25%<br>・H - 約30% |
